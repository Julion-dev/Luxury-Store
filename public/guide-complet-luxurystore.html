Guide Pratique de Modification du Projet

Comprendre et modifier votre boutique e-commerce étape par étape en tant que débutant

🎉 Félicitations pour avoir validé le module HTML !

Le HTML est la fondation de tout le web mondial. Tout ce que vous voyez sur ce site (les titres, les paragraphes, les images, les formulaires et les boutons) repose sur les balises HTML que vous venez d'apprendre. Ce guide est spécialement écrit pour faire le pont entre vos nouvelles connaissances et ce projet.

1 C'est quoi ces extensions bizarres (.tsx, .ts, .xml, .json) ?

Ne soyez pas intimidé par ces extensions. Voici ce qu'elles veulent dire en langage simple :

Extension Ce que c'est en réalité Comparaison avec ce que vous connaissez
.tsx TypeScript + HTML (JSX) C'est exactement du HTML (comme <h1>, <div>, <button>), mais combiné avec du JavaScript pour rendre la page interactive.
.ts TypeScript pur C'est du JavaScript normal, avec une sécurité en plus pour éviter de taper des fautes dans les noms de variables.
.json Données pures C'est un simple fichier texte de réglages (comme un carnet d'adresses ou une liste de paramètres).
.xml Plan du site Un plan textuel pour aider Google à référencer vos pages.

2 LE FICHIER MAÎTRE : src/data/mockData.ts

C'est LE fichier le plus important pour vous. Il contient tous les produits, leurs prix, les photos et les avis clients, sous la forme d'une liste très facile à lire.

👟 Exemple : Modifier une paire de sneakers ou un smartphone src/data/mockData.ts

Ouvrez ce fichier dans VS Code. Vous verrez un bloc comme celui-ci :

{
  id: 1,
  title: 'Air Jordan 1 Retro High OG',   // ⬅️ Le nom du produit
  category: 'sneakers',                 // ⬅️ La catégorie ('sneakers', 'smartphones', 'accessories')
  brand: 'jordan',                      // ⬅️ La marque
  price: 299.99,                        // ⬅️ Le prix en euros
  oldPrice: 349.99,                     // ⬅️ (Optionnel) Ancien prix barré
  badge: 'Nouveau',                     // ⬅️ Le badge ('Nouveau', '-15%', 'Édition Limitée')
  description: "L'iconique Air Jordan...", // ⬅️ La description du produit
  image: 'https://images.unsplash.com/...', // ⬅️ Le lien de la photo
}
💡 Comment changer le prix : Remplacez simplement 299.99 par 199.99 et faites Ctrl + S. Le navigateur se mettra à jour en direct !

3 Modifier l'Adresse, Téléphone, Email et Emplacement

📍 Page Contact & Showroom src/pages/ContactPage.tsx

Pour changer les coordonnées de contact de votre entreprise :

  • Adresse physique : vers la ligne 65, cherchez le texte 123 Rue du Luxe, 75001 Paris et écrivez votre vraie adresse.
  • Téléphone : vers la ligne 75, modifiez +33 1 23 45 67 89.
  • Email : vers la ligne 86, modifiez contact@luxurystore.com.
  • Carte Google Maps : vers la ligne 255, vous trouverez une balise <iframe src="...">. Pour changer le lieu, allez sur Google Maps sur internet, cliquez sur Partager > Intégrer une carte, et collez le lien dans le src.
🔻 Pied de page (Footer) src/components/Footer.tsx

Le pied de page apparaît sur toutes les pages du site :

  • Les coordonnées en bas (lignes 170-185).
  • La ligne de copyright avec votre nom : © 2025 LuxuryStore — Créé avec excellence par Julien Mastaki.

4 Modifier le Nom de la Boutique et le Titre de l'onglet

🏷️ Nom du site dans l'onglet du navigateur index.html

Comme vous venez de terminer le module HTML, vous connaissez cette balise ! Ouvrez index.html :

<title>Luxury Store</title>
<meta name="description" content="Boutique en ligne premium..." />

Changez le texte entre les balises <title> et </title> pour donner le titre que vous voulez à votre site.

💎 Logo dans la barre de navigation src/components/Navbar.tsx

Aux lignes 37 à 40, vous trouverez le code du logo :

<span>LUXURY</span>
<span className="text-[#e74c3c]">STORE</span>

Vous pouvez remplacer ces deux mots par le nom de votre choix.

5 Modifier l'Histoire de l'Entreprise et l'Équipe

📖 Histoire et présentation src/pages/AboutPage.tsx

Dans ce fichier, vous pouvez modifier en texte direct :

  • L'année de fondation (ex: 2018).
  • Le paragraphe "Qui sommes-nous ?" (lignes 35-50).
  • Les chiffres clés (5+ années d'expérience, 10K+ clients satisfaits).
  • La section livraison et retours (lignes 160-190).

6 Utiliser Vos Propres Photos (100% Hors-Ligne)

Pour afficher vos propres photos sans avoir besoin d'internet :

  1. Prenez vos images (ex: jordan4.jpg ou mon-magasin.png).
  2. Copiez-les dans le dossier public/ à la racine de votre projet dans VS Code.
  3. Ouvrez src/data/mockData.ts et écrivez simplement : 
    image: '/jordan4.jpg',

L'image s'affichera immédiatement dans votre navigateur, même sans aucune connexion internet !

7 Aide-Mémoire des Commandes Quotidiennes

Pour travailler chaque jour sur votre projet :

  1. Ouvrez VS Code.
  2. Ouvrez votre terminal (Terminal > Nouveau terminal ou Ctrl + ~).
  3. Tapez : 
    npm run dev
  4. Ouvrez http://localhost:3000 dans votre navigateur.
  5. Faites vos modifications dans les fichiers, enregistrez avec Ctrl + S et admirez le résultat en direct !
  6. Pour éteindre le serveur en fin de journée : faites Ctrl + C dans le terminal.
