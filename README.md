# LuxuryStore - Portfolio E-commerce

![Bannière LuxuryStore](assets/images/banner.jpg)

Portfolio professionnel pour un business e-commerce spécialisé en sneakers et smartphones haut de gamme.

- ✨ **Animations fluides** (GSAP & CSS3)
